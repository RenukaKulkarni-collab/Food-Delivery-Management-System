# Food Delivery Management System

## Project Overview
The Food Delivery Management System is a database project developed using Microsoft SQL Server. It manages food delivery operations, including customers, restaurants, menu items, orders, payments, delivery partners, and reviews.

## Technologies Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Database Tables
1. Users
2. Addresses
3. Restaurants
4. Categories
5. DeliveryPartners
6. Orders
7. MenuItems
8. Order_Items
9. Payments
10. Deliveries
11. Reviews

## Key Concepts Practiced
- DDL and DML
- Primary Keys and Foreign Keys
- Constraints
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Data Analysis Queries

## Project Files
- `01_Create_Tables.sql` – Database table creation
- `02_Insert_Data.sql` – Sample data insertion
- `03_Queries.sql` – SQL queries and reports
- `Project_Report.docx` – Project documentation

## How to Run
1. Open SQL Server Management Studio.
2. Create a database named `FoodDeliveryDB`.
3. Execute `01_Create_Tables.sql`.
4. Execute `02_Insert_Data.sql`.
5. Execute `03_Queries.sql`.
